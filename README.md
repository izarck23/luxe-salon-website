# Salon Website

A modern salon website built with HTML, CSS, and JavaScript. This project is designed to help salon owners present their services professionally, attract more clients, and make booking easier for visitors.

---

## What This Website Is For

This website helps a salon:
- showcase services in a clean and attractive way
- display service images and prices
- let visitors preview services in a modal
- provide a fast booking option through WhatsApp
- build trust with a polished, professional online presence

Instead of depending only on social media or word of mouth, the salon can have a dedicated online space where customers can learn about services and contact the business easily.

---

## Main Features

- Responsive layout for desktop, tablet, and mobile
- Hero section with strong visual branding
- Service section with images, descriptions, and prices
- Clickable service images that open a modal preview
- Book Now button that can open WhatsApp or a booking page
- Gallery section for showcasing salon work
- Testimonials section for customer feedback
- Contact and booking section for inquiries
- Distinct footer with social media links and terms page
- Smooth scrolling and polished visual design

How to Run the Website
Simply open index.html in your browser.

If you use VS Code, you can install the Live Server extension for easier preview and automatic refresh.

How to Deploy on GitHub Pages

-Push the project to a GitHub repository
-Make sure index.html is in the root folder
-Go to repository settings
-Open Pages
-Select your branch and root folder
-Save the settings
Your website will go live on GitHub Pages
